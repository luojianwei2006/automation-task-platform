## 需求补充（2026-05-02）

- 用户补充需求：安卓端需增加自动化操作功能
- 经过技术可行性分析后，确认增加三种自动化模式
- 模式一：手动执行（默认，无需权限）
- 模式二：半自动引导模式（使用 Accessibility Service，需无障碍服务+悬浮窗权限）
- 模式三：深度自动化模式（使用 Root + Xposed，自动化程度最高但风险最高）
- 三种模式可在「个人中心 → 自动化设置」中自由切换
- 深度自动化模式需用户签署风险免责协议
- PRD 已更新，增加「3.2.6 自动化操作模式」章节和技术选型说明

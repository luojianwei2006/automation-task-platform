## 1. 调和后总体架构

```
┌─────────────┐    EditInstruction(JSON)     ┌──────────────────────┐
│  安卓 App    │ ───────────────────────────▶ │  后端 task-admin-api  │
│ VideoEditor  │                              │  MergePreviewService  │
│  - 时间轴UI   │ ◀──── 结果URL(异步轮询) ──────│  (FFmpeg 最终渲染)     │
│  - 本地预览   │                              │  + video_edit_task     │
└─────────────┘                              └──────────────────────┘
        │                                            ▲
        │ 本地预览(ExoPlayer+特效+Canvas叠加)          │ 编辑指令同源
        │ 不重新编码，仅所见即所得                      │
┌─────────────┐                              ┌──────────────────────┐
│ 管理后台 Vue │ ── 同套 EditInstruction ────▶│  (复用同一渲染管线)    │
└─────────────┘                              └──────────────────────┘
```

**核心调和点**：同一份 `EditInstruction` JSON 驱动两端。
- **安卓**：用 `EditInstruction` 驱动**实时预览**（ExoPlayer 视频特效 + Compose Canvas 叠加），用户拖拽滑块即时看到效果，**此过程不调用后端、不重新编码**。
- **后端**：用户点"生成/发布"时，安卓/后台把 `EditInstruction` 发给 `MergePreviewService`，解析为 FFmpeg `filter_complex` 链做**最终高质量渲染**，异步落库 `video_edit_task`，结果 URL 回传。

这样既满足"本地实时预览"体验，又保留服务端渲染的质量/一致性/省电优势，且复用现有 `MergePreviewController`+`PublishMergeHistory` 异步范式。

## 2. 编辑指令 JSON Schema（精化版）

```json
{
  "timeline": {
    "width": 1080,
    "height": 1920,
    "background": "#000000",
    "segments": [
      {
        "assetId": "vid_001",
        "src": "/uploads/publish/vid_001.mp4",
        "trim": { "start": 1.5, "end": 8.0 },
        "rotate": 90,
        "mirror": false,
        "speed": 1.0,
        "crop": { "x": 0, "y": 0, "w": 1080, "h": 1920 },
        "filterPreset": "fresh",
        "volume": 1.0,
        "subtitles": [
          { "start": 1.5, "end": 4.0, "text": "第一行字幕", "size": 36, "color": "#FFFFFF", "position": "bottom", "align": "center" }
        ],
        "overlays": [
          { "type": "image", "src": "/uploads/publish/logo.png", "x": 40, "y": 40, "w": 200, "h": 200, "start": 0, "end": 6.5 }
        ]
      }
    ],
    "transitions": [
      { "type": "fade", "duration": 0.5 }
    ]
  },
  "audio": {
    "originalVolume": 1.0,
    "bgm": [
      { "src": "/uploads/music/bgm_01.mp3", "volume": 0.3, "loop": true, "fadeIn": 1.0, "fadeOut": 1.0 }
    ],
    "voiceover": [
      { "src": "/uploads/audio/vo_01.mp3", "volume": 1.0, "start": 2.0 }
    ]
  },
  "output": { "ratio": "9:16", "quality": "high" }
}
```

**字段生效说明**：
- 安卓预览支持：trim（播放区间）、rotate/mirror、speed、crop（Matrix）、filterPreset（GL 近似）、subtitles（Canvas 文本）、overlays（Canvas 图片）、originalVolume、bgm/voiceover（多轨混音预览）。
- 仅后端渲染生效（预览用近似）：filterPreset 的精确色彩、overlays 的最终合成像素、转场 xfade 帧精度。

## 3. 后端改造设计（task-admin-api）

### 3.1 MergePreviewService 扩展
新增 `buildFilterComplex(EditInstruction)` 方法，按 segment 生成 FFmpeg 链：

| 能力 | FFmpeg 片段示例 |
|------|----------------|
| trim | `[0:v]trim=start=1.5:end=8.0,setpts=PTS-STARTPTS[v0]` |
| rotate | `[v0]rotate=PI/2[v0r]`（mirror 用 `hflip`） |
| speed | `[v0r]setpts=PTS/{speed}[v0s]`（配合 atempo 音频） |
| crop/画幅 | `[v0s]scale=1080:1920:force_original_aspect_ratio=decrease,pad=1080:1920:(ow-iw)/2:(oh-ih)/2[v0c]` |
| 滤镜预设 | `[v0c]eq=brightness=0.06:saturation=1.25:contrast=1.05[v0f]`（见 3.2） |
| 字幕(逐段) | `[v0f]drawtext=text='...':fontsize=36:fontcolor=white:x=(w-text_w)/2:y=h-th-40:enable='between(t,1.5,4.0)'[v0sub]` |
| 图片PiP | `[v0sub][img]overlay=40:40:enable='between(t,0,6.5)'[v0ov]` |
| 多段拼接+转场 | `concat` / `xfade=transition=fade:duration=0.5` |
| 多轨音频 | `[0:a][bgm]amix=inputs=2[aud]` + `volume` + `afade` |

### 3.2 八滤镜预设（FFmpeg 参数映射）
| 预设ID | 名称 | FFmpeg 参数 |
|--------|------|-------------|
| none | 原片 | （无） |
| fresh | 清新 | `eq=brightness=0.06:saturation=1.25:contrast=1.05` |
| warm | 暖阳 | `eq=brightness=0.04:contrast=1.08:saturation=1.1`,`colorbalance=rs=0.08:bs=-0.08` |
| film | 胶片 | `eq=contrast=1.2:brightness=-0.02:gamma=1.1:saturation=1.05` |
| gray | 黑白 | `format=gray` |
| vintage | 复古 | `eq=contrast=1.1:saturation=0.85:brightness=0.03`,`colorbalance=rs=0.1:bs=-0.05` |
| cool | 冷调 | `eq=saturation=1.05`,`colorbalance=bs=0.1:rs=-0.08` |
| jpn | 日系 | `eq=brightness=0.05:contrast=0.95:saturation=0.9` |

### 3.4 数据库（新增表）
```sql
CREATE TABLE t_video_edit_task (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  project_id BIGINT,
  instruction_json TEXT NOT NULL,
  status TINYINT DEFAULT 0 COMMENT '0待处理 1渲染中 2成功 3失败',
  result_url VARCHAR(512),
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  INDEX idx_project (project_id)
);
```

## 4. 安卓端设计

### 4.1 VideoEditorScreen 组件结构
```
VideoEditorScreen
├── TimelineRow        // 片段卡片横向列表（点选=当前编辑段）
├── PreviewSurface     // AndroidView 包裹 PlayerView，ExoPlayer 实时预览
├── SegmentPanel       // 选中段后弹出：trim滑块/旋转/调速/画幅/滤镜选择/音量
├── SubtitleLayer      // Compose Canvas，按 playback position 叠字幕
├── OverlayLayer       // Compose Canvas，叠图片PiP
└── BottomBar          // 滤镜预设快捷条 + "生成"按钮(提交后端)
```

### 4.2 本地实时预览引擎（关键）
- **旋转/镜像**：`ExoPlayer.setVideoEffects(listOf(ScaleAndRotateTransformation(rotationDegrees, scaleX=镜像?-1:1)))`
- **滤镜预设**：Media3 `effect` 包内置 `Brightness`/`Contrast`/`Saturation`/`Hue`/`ColorFilter`，按 8 预设组合成 `List<Effect>`；`gray` 用 `ColorFilter(Matrix grayscale)`，`vintage/cool/warm` 用 `ColorFilter` 自定义 4x4 矩阵近似。
- **trim**：`ClippingMediaSource` 或播放时 `seekTo(start)`+监听到 end 停；预览不重编码。
- **speed**：`player.playbackParameters = PlaybackParameters(speed)`
- **字幕/图片PiP**：Compose `Canvas` 叠加层，按 `player.currentPosition` 实时绘制（与后端 drawtext/overlay 参数同源）。
- **关键类**：`PreviewEngine`（持有 ExoPlayer+Effect 列表+Canvas 状态）、`EditInstruction`（Kotlin data class，与 JSON 1:1）、`FilterPresets`（8 枚举常量，与后端 `FilterPreset.java` 完全一致）。

### 4.3 预览↔渲染对齐（防"预览好看导出崩"）
- 两端共用同一 `FilterPreset` 枚举 ID（安卓 `FilterPresets`、`后端 FilterPreset.java` 值必须相同）。
- trim/rotate/speed/crop 数值原样透传后端；滤镜用同一组数学参数（安卓 GL 近似仅影响预览观感，后端为最终真值）。
- 提交时把 `EditInstruction` 序列化为 JSON 发后端，后端原样解析渲染。

## 7. 依赖与风险
- **FFmpeg**：需 `>=4.3` 以支持 `colorbalance`/`xfade`；部署镜像确认已含。
- **安卓 Media3**：`androidx.media3:media3-effect` + `media3-exoplayer`（`ScaleAndRotateTransformation`/`Brightness` 等内置 Effect 需 Media3 1.1+）。
- **GL 滤镜偏差**：安卓预览用 GL 近似，后端用 FFmpeg 真值，极端预设（vintage/cool）可能有观感差 → 以后端导出为准，预览仅参考。
- **大视频预览性能**：4K 视频实时特效可能掉帧 → 预览用 `SurfaceView`+降级分辨率，导出用原分辨率。
- **本地无 mvn**：后端改动需在你有 mvn 的环境编译验证。

## 8. 共享知识（跨端约定）
- `FilterPreset` 枚举值两端必须完全一致：`none/fresh/warm/film/gray/vintage/cool/jpn`。
- 时间单位统一**秒**（浮点）；坐标统一**像素**（基于 output 分辨率）；字幕 position 取值 `top/bottom/middle`。
- EditInstruction JSON 字段名两端严格一致（Kotlin data class ↔ Java DTO ↔ TS interface）。

### 2.2 微服务拆分策略（一期）

**一期采用单体架构 + 逻辑分层**，二期根据实际负载情况考虑微服务拆分。

| 服务模块 | 职责 | 数据库 |
|----------|------|--------|
| 用户服务 | 注册/登录/实名认证/个人信息管理 | t_user, t_user_earnings, t_invite_relation |
| 任务服务 | 任务发布/接取/提交/审核 | t_task, t_user_task_record, t_notification |
| 广告服务 | 广告投放/观看/奖励 | t_ad, t_ad_record |

| 系统服务 | 消息通知/审计日志/系统配置 | t_notification, t_audit_log |

### 2.3 数据流设计

#### 2.3.1 任务接单数据流

```
用户接单 → 后端校验(用户状态/任务状态/接单次数) 
→ 创建任务记录(t_user_task_record) 
→ 返回任务详情 
→ 用户执行任务(手动/半自动/深度自动) 
→ 上传截图 
→ AI审核(腾讯云AI) 
→ 审核通过 → 更新收益(t_user_earnings) → 通知用户
→ 审核失败 → 通知用户 → 可重新提交(限1次)
→ 重新提交 → 状态从3(拒绝)回1(待审核) → 再次AI审核
```

#### 2.3.2 提现数据流

```
用户申请提现 → 校验(实名认证/收款账户/余额) 
→ 创建提现记录(t_withdraw_record) 
→ 判断金额:
   ≤200元 → 自动打款(微信/支付宝API) → 更新状态(已打款) → 通知用户
   >200元 → 进入人工审核队列 → 审核通过 → 手动打款 → 通知用户
```

#### 2.3.3 广告观看数据流

```
用户点击广告 → 调用开始观看接口（服务端记录开始时间）
→ 播放广告素材
→ 用户观看完成 → 调用观看完成接口（服务端计算时长）
→ 时长 ≥ 要求时长 → 发奖（更新 t_user_earnings）→ 通知用户
→ 时长 < 要求时长 → 返回错误（错误码1404）
```

```kotlin
class AuthInterceptor : Interceptor {
    override fun intercept(chain: Interceptor.Chain): Response {
        val originalRequest = chain.request()
        val token = DataStoreManager.getToken() // 从本地存储获取Token
        
        return if (token != null) {
            val newRequest = originalRequest.newBuilder()
                .header("Authorization", "Bearer $token")
                .build()
            chain.proceed(newRequest)
        } else {
            chain.proceed(originalRequest)
        }
    }
}
```

```kotlin
// automation/TaskAccessibilityService.kt
class TaskAccessibilityService : AccessibilityService() {
    
    companion object {
        const val ACTION_LIKE_DETECTED = "com.task.platform.ACTION_LIKE_DETECTED"
        const val ACTION_COMMENT_DETECTED = "com.task.platform.ACTION_COMMENT_DETECTED"
        const val ACTION_PAGE_CHANGED = "com.task.platform.ACTION_PAGE_CHANGED"
    }
    
    override fun onAccessibilityEvent(event: AccessibilityEvent?) {
        when (event?.eventType) {
            AccessibilityEvent.TYPE_VIEW_CLICKED -> {
                handleClickEvent(event)
            }
            AccessibilityEvent.TYPE_WINDOW_STATE_CHANGED -> {
                handlePageChange(event)
            }
            AccessibilityEvent.TYPE_VIEW_TEXT_CHANGED -> {
                handleTextChange(event)
            }
        }
    }
    
    private fun handleClickEvent(event: AccessibilityEvent) {
        val node = event.source ?: return
        
        // 检测点赞按钮
        if (isLikeButton(node)) {
            // 发送广播通知主APP
            val intent = Intent(ACTION_LIKE_DETECTED)
            sendBroadcast(intent)
            
            // 显示悬浮窗提示
            FloatingWindowManager.showHint("检测到点赞操作，请返回APP提交审核")
        }
    }
    
    private fun isLikeButton(node: AccessibilityNodeInfo): Boolean {
        val resourceId = node.viewIdResourceName ?: ""
        val text = node.text?.toString() ?: ""
        
        return resourceId.contains("like", ignoreCase = true) ||
               text.contains("赞") ||
               resourceId.contains("heart", ignoreCase = true)
    }
    
    private fun handlePageChange(event: AccessibilityEvent) {
        val packageName = event.packageName?.toString() ?: return
        
        // 检测是否跳转到目标App
        if (packageName == "com.ss.android.ugc.aweme" ||  // 抖音
            packageName == "com.xingin.xhs") {  // 小红书
            
            val intent = Intent(ACTION_PAGE_CHANGED)
            intent.putExtra("package_name", packageName)
            sendBroadcast(intent)
        }
    }
    
    override fun onInterrupt() {
        // 服务被中断时的处理
    }
    
    override fun onServiceConnected() {
        super.onServiceConnected()
        // 服务连接成功后的初始化
    }
}
```

```kotlin
// viewmodel/SettingsViewModel.kt
class SettingsViewModel : ViewModel() {
    
    private val _autoMode = MutableStateFlow(0) // 0:手动 1:半自动 2:深度自动
    val autoMode: StateFlow<Int> = _autoMode.asStateFlow()
    
    private val _permissionStatus = MutableStateFlow(PermissionStatus())
    val permissionStatus: StateFlow<PermissionStatus> = _permissionStatus.asStateFlow()
    
    init {
        // 从本地存储读取当前模式
        val savedMode = DataStoreManager.getAutoMode()
        _autoMode.value = savedMode
        
        // 检测权限状态
        checkPermissions()
    }
    
    fun switchAutoMode(mode: Int) {
        when (mode) {
            0 -> {
                // 手动模式：无需额外权限
                updateMode(mode)
            }
            1 -> {
                // 半自动：需要无障碍服务+悬浮窗权限
                if (checkAccessibilityService() && checkOverlayPermission()) {
                    updateMode(mode)
                } else {
                    // 引导用户授权
                    _permissionStatus.value = PermissionStatus(
                        needAccessibility = !checkAccessibilityService(),
                        needOverlay = !checkOverlayPermission()
                    )
                }
            }
            2 -> {
                // 深度自动化：需要Root+Xposed
                if (checkRoot() && checkXposed()) {
                    // 显示风险告知书
                    showRiskDisclaimer()
                } else {
                    _permissionStatus.value = PermissionStatus(
                        needRoot = !checkRoot(),
                        needXposed = !checkXposed()
                    )
                }
            }
        }
    }
    
    private fun updateMode(mode: Int) {
        _autoMode.value = mode
        DataStoreManager.setAutoMode(mode)
    }
    
    private fun checkAccessibilityService(): Boolean {
        // 检查无障碍服务是否已开启
        val enabledServices = Settings.Secure.getString(
            appContext.contentResolver,
            Settings.Secure.ENABLED_ACCESSIBILITY_SERVICES

        return Settings.canDrawOverlays(appContext)

        return XposedUtil.isXposedInstalled()
```

```java
// task-common/src/main/java/com/task/common/utils/JwtUtils.java
@Component
public class JwtUtils {
    
    @Value("${jwt.secret}")
    private String secret;
    
    @Value("${jwt.expiration}")
    private Long expiration;
    
    @Value("${jwt.refresh-expiration}")
    private Long refreshExpiration;
    
    /**
     * 生成Token
     */
    public String generateToken(Long userId, String phone, Integer role) {
        Date now = new Date();
        Date expiryDate = new Date(now.getTime() + expiration);
        
        return Jwts.builder()
                .setSubject(userId.toString())
                .claim("phone", phone)
                .claim("role", role)
                .setIssuedAt(now)
                .setExpiration(expiryDate)
                .signWith(SignatureAlgorithm.HS512, secret)
                .compact();
    }
    
    /**
     * 生成RefreshToken
     */
    public String generateRefreshToken(Long userId) {
        Date now = new Date();
        Date expiryDate = new Date(now.getTime() + refreshExpiration);
        
        return Jwts.builder()
                .setSubject(userId.toString())
                .setIssuedAt(now)
                .setExpiration(expiryDate)
                .signWith(SignatureAlgorithm.HS512, secret)
                .compact();
    }
    
    /**
     * 从Token中获取用户ID
     */
    public Long getUserIdFromToken(String token) {
        Claims claims = Jwts.parser()
                .setSigningKey(secret)
                .parseClaimsJws(token)
                .getBody();
        return Long.parseLong(claims.getSubject());
    }
    
    /**
     * 验证Token
     */
    public boolean validateToken(String token) {
        try {
            Jwts.parser().setSigningKey(secret).parseClaimsJws(token);
            return true;
        } catch (Exception e) {
            return false;
        }
    }
}
```

#### 4.2.3 任务接取服务（幂等性保证）

```java
// task-task-service/src/main/java/com/task/task/service/TaskService.java
@Service
@RequiredArgsConstructor
public class TaskService {
    
    private final TaskMapper taskMapper;
    private final UserTaskRecordMapper userTaskRecordMapper;
    private final RedisTemplate<String, Object> redisTemplate;
    
    /**
     * 接受任务（幂等设计）
     * 重复调用返回已有记录，不创建新记录
     */
    @Transactional
    public TaskRecordDTO acceptTask(Long userId, Long taskId) {
        // 1. 检查任务是否存在且状态正常
        Task task = taskMapper.selectById(taskId);
        if (task == null || task.getStatus() != 1) {  // 1=已上架
            throw new BusinessException(ErrorCode.TASK_NOT_AVAILABLE);
        }
        
        // 2. 检查是否已接取（幂等性保证）
        UserTaskRecord existRecord = userTaskRecordMapper.selectByUserIdAndTaskId(userId, taskId);
        if (existRecord != null) {
            // 已接取，直接返回已有记录
            return convertToDTO(existRecord);
        }
        
        // 3. 检查任务配额
        if (task.getUsedQuota() >= task.getTotalQuota()) {
            throw new BusinessException(ErrorCode.TASK_QUOTA_EXCEEDED);
        }
        
        // 4. 创建任务记录
        UserTaskRecord record = new UserTaskRecord();
        record.setUserId(userId);
        record.setTaskId(taskId);
        record.setStatus(0);  // 0=进行中
        record.setSubmitCount(0);
        record.setCreatedAt(LocalDateTime.now());
        
        userTaskRecordMapper.insert(record);
        
        // 5. 更新任务已用配额
        taskMapper.incrementUsedQuota(taskId);
        
        return convertToDTO(record);
    }
    
    /**
     * 提交任务（幂等设计）
     * 第2次提交返回「已提交，请等待审核」
     */
    @Transactional
    public TaskRecordDTO submitTask(Long userId, Long taskId, MultipartFile screenshot) {
        // 1. 查询任务记录
        UserTaskRecord record = userTaskRecordMapper.selectByUserIdAndTaskId(userId, taskId);
        if (record == null) {
            throw new BusinessException(ErrorCode.TASK_NOT_ACCEPTED);
        }
        
        // 2. 检查是否已提交（幂等性保证）
        if (record.getStatus() != 0) {  // 0=进行中
            throw new BusinessException(ErrorCode.TASK_ALREADY_SUBMITTED, "已提交，请等待审核");
        }
        
        // 3. 上传截图到COS
        String screenshotUrl = cosService.upload(screenshot);
        
        // 4. 更新任务记录
        record.setScreenshotUrl(screenshotUrl);
        record.setStatus(1);  // 1=待审核
        record.setSubmitCount(record.getSubmitCount() + 1);
        record.setSubmittedAt(LocalDateTime.now());
        
        userTaskRecordMapper.updateById(record);
        
        // 5. 发送消息到RabbitMQ，触发AI审核
        rabbitTemplate.convertAndSend("task.exchange", "task.audit", record.getId());
        
        return convertToDTO(record);
    }
}
```

```javascript
import store from '@/store'

const service = axios.create({
  baseURL: process.env.VUE_APP_BASE_API,

// 请求拦截器
service.interceptors.request.use(
  config => {
    // 添加Token
    if (store.getters.token) {
      config.headers['Authorization'] = 'Bearer ' + store.getters.token
    }
    return config
  },
  error => {
    return Promise.reject(error)
  }
)

// 响应拦截器
service.interceptors.response.use(
  response => {
    const res = response.data
    
    if (res.code !== 200) {
      ElMessage.error(res.msg || '请求失败')
      
      // Token过期处理
      if (res.code === 401) {
        store.dispatch('user/resetToken').then(() => {
          router.push('/login')
        })
      }
      
      return Promise.reject(new Error(res.msg || 'Error'))
    } else {
      return res
    }
  },
  error => {
    ElMessage.error(error.message || '网络异常')
    return Promise.reject(error)
  }
)
```

## 十、开发规范

### 10.1 代码规范

**Java**
- 遵循《阿里巴巴Java开发手册》
- 使用CheckStyle检查代码风格
- 使用SonarQube进行代码质量检测

**Kotlin**
- 遵循Kotlin官方编码规范
- 使用ktlint进行代码格式化

**Vue**
- 遵循Vue 3风格指南
- 使用ESLint + Prettier

### 10.2 提交规范

遵循Angular提交规范：
```
feat: 新功能
fix: 修复bug
docs: 文档更新
style: 代码格式调整
refactor: 重构
test: 测试相关
chore: 构建/工具配置
```

示例：
```
feat(task): 添加任务接取接口
fix(user): 修复用户登录Token过期问题
```

### 10.3 分支管理

```
master - 生产分支（保护分支，只允许合并）
  │
  ├── develop - 开发分支
  │     │
  │     ├── feature/task-module - 功能分支
  │     ├── feature/user-module
  │     └── ...
  │
  └── hotfix/login-fix - 紧急修复分支
```

**工作流程**
1. 从develop分支创建feature分支
2. 开发完成后提交Pull Request到develop
3. Code Review通过后合并
4. develop分支测试通过后合并到master
5. master分支打标签发布

## 十二、风险评估与对策

| 风险 | 等级 | 对策 |
|------|------|------|
| 抖音/小红书接口变动（Deep Link失效） | 高 | 定期抓包验证，发现失效立即更新；提供手动模式兜底 |
| 自动化模式被平台检测 | 高 | 深度自动化模式需用户签署免责；设置任务频率上限 |
| Xposed模块兼容性问题 | 中 | 开发多版本适配主流机型；提供手动模式作为降级方案 |
| AI审核误判率高 | 中 | 一期先人工复审兜底；持续优化AI模型阈值 |
| 用户刷单作弊 | 中 | 设备指纹+行为分析+AI识别多维度风控 |
| 支付接口合规风险 | 中 | 初期人工操作打款；规模达到后接入持牌支付公司 |
| 数据库性能瓶颈 | 低 | MySQL主从读写分离；Redis缓存热点数据 |
| 应用市场审核被拒 | 中 | Android包名不包含敏感词；Xposed模块独立打包不入主包 |
